# LCRP Models Directory

This directory contains the model implementations for the LCRP (Layer-wise Concept Relevance Propagation) framework.

## Note
The original model files (including pidnet.py, yolov6.py, etc.) were part of a git submodule that has been converted to regular files. The large checkpoint files (.pt files) have been excluded to comply with GitHub's file size limits.

## Structure
- `checkpoints/` - Model checkpoint files (excluded from git due to size)
- Model implementation files will be restored/recreated as needed
